## 2. Protocol for Adding Future WoW: Forever Research Skills & Tools

Whenever new community `SKILL.md` packages, MCP servers, or theorycrafting tools for *World of Warcraft: Forever* are released:

1. **Automated Discovery Check:** Run `python3 .agents/skills/wow-forever/scripts/wow_forever_query.py ecosystem` to query `everloot.ecosystem_projects` and `everloot.recent_changes`, and search GitHub for `wow-forever` + `SKILL.md` or `mcp`.
2. **Provenance Logging:** Add a row to the Provenance Ledger above recording the upstream repository URL, commit/tag/version evaluated, date, borrowed concepts, local divergence, and re-evaluation triggers.
3. **Skill Integration:**
   - Merge new query endpoints or data tables into `.agents/skills/wow-forever/scripts/wow_forever_query.py`.
   - Update `.agents/skills/wow-forever/SKILL.md` with conditional tool instructions (working across both Antigravity and Codex).
   - Keep personal character progression state strictly in `.local/system-context/wow-forever-profile.md`.
