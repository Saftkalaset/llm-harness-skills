# Working preferences

Source: User-confirmed system preferences.

- Prefer existing installation methods (e.g. Snap for auto-updating desktop apps, APT with official DEB822 repos for developer tools).
- Keep changes easy to maintain and reversible.
- Discuss downtime before touching running background services or daemons.
- Discover relevant system information via read-only commands before asking repeat setup questions.
- When asking questions, provide a recommended option / best guess and allow free-form correction.
- Present ad-hoc reviews, audits, comparisons, and status deliverables as standalone styled HTML opened in Firefox rather than raw Markdown.
- In terminal responses, format items, options, and findings in structured Markdown tables for rapid scanning.
- Keep context available to both Codex and Antigravity harnesses.

These preferences guide choices; they do not grant execution permissions or authorize unrelated changes.
